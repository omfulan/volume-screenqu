# Volume Screen Control ASUS - Simple UI

Versi sederhana untuk Android lama/ASUS.

## Tampilan
Hanya ada:
- indikator AKTIF/NONAKTIF
- satu tombol ON/MATIKAN

## Fungsi
Saat AKTIF:
- Volume UP = layar ON/wake
- Volume DOWN = layar OFF/lock

Saat MATIKAN:
- aplikasi tidak memproses tombol volume.

## Aktivasi pertama
Tekan ON. Jika izin belum lengkap, aplikasi akan membuka halaman Android yang diperlukan satu per satu. Setelah selesai, kembali ke aplikasi dan tekan ON lagi.

Android tidak mengizinkan aplikasi mengaktifkan Accessibility Service secara diam-diam. Pada ASUS tertentu, Auto-start/Power Management juga perlu mengizinkan aplikasi berjalan otomatis.

## Kompatibilitas
Min SDK 26 (Android 8.0)
Target SDK 28 (Android 9)
Compile SDK 35
